# Grand Aventures Web

> El sitio web que hemos diseñado en este Sprint 2 corresponde con un servicio web de una agencia de reserva de actividades turísticas. El objetivo es que el usuario pueda explorar las actividades ofertadas, registrarse, realizar reservas y gestionarlas.

## Contenido del sprint

Durante el sprint se ha añadido la carga dinámica del contenido de las páginas del sitio web, se añadió validación en los formularios para registro e inicio de sesión y se convirtión en un sitio web responsivo, adaptado a tres tipos de dispositivos, teléfonos, con un máximo de 767 píxeles, tablets, con 1024 píxeles como máximo, y desktop, para anchos superiores.

### Contenido extra

En añadido a lo anterior, se ha creado un sistema interactivo de registro e inicio de sesión, que permite al usuario registrarse e iniciar sesión mediante el almacenamiento de sessionStorage. Asimismo, se añadieron funcionalidades interactivas como la posibilidad de realizar búsquedas mediante la barra de búsqueda, filtrar actividades por distintos aspectos y un sistema interactivo para realizar reservas, preparando el sitio web para ser plenamente funcional.
